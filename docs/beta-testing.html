Pre-release beta · ~10 minutes

Help test Academic Document Checker

doc-checker is a command-line tool that checks a Word document (thesis chapter, journal manuscript, grant proposal) against a set of academic formatting and citation rules. It just went up on PyPI. Before we tell more people about it, we want a handful of real people running it on a real document of theirs — that's you.

🧪 v0.4.1 beta 📄 Needs a .docx, .txt or .md file 💻 Windows, Mac or Linux

Before you start

  • A computer with Python already on it, or you're happy installing it (step 1 covers this)
  • One document of yours to test with — a thesis chapter, paper draft, or grant proposal, saved as .docx
  • About 10 minutes, most of it waiting on installs
1

Make sure Python is installed

Open a terminal (see step 2 if you're not sure how) and run:

python --version

Expect to see: something like Python 3.11.4

If that fails, or shows Python 2.x, install Python from python.org/downloads first — on the first install screen, tick "Add Python to PATH" if you're on Windows, then come back here.

2

Open a terminal

🪟 Windows 🍎 Mac

Windows: press the Windows key, type PowerShell, press Enter.
Mac: press Cmd + Space, type Terminal, press Enter.

You'll type every command below into that window, then press Enter.

3

Install the tool

pip install academic-document-checker

Expect to see: a few lines ending in Successfully installed academic-document-checker-0.4.1b1

4

Check it worked

doc-checker --version

Expect to see: doc-checker, version 0.4.1b1

If it says "command not found": close and reopen your terminal, then try again — this usually fixes it on Windows. Still stuck? Skip to the FAQ at the bottom.
5

Run it on your document

Put the document you want to test somewhere easy to find (like your Desktop), then run:

# replace the filename with your own, keep the quotes
doc-checker check "My Thesis Chapter.docx" --profile generic --format html --output report.html

Swap "My Thesis Chapter.docx" for your file's actual name. If your terminal is in a different folder than the document, either move the document there, or type the full path in quotes instead of just the filename.

The --profile flag picks which rules it checks against:

ProfileBest for
genericAny academic document — the safe default
phd-thesisThesis or dissertation chapters
medical-journalMedical/clinical journal manuscripts
uk-academic-manuscriptBritish-English spelling + Vancouver referencing
6

Open the report

That command created a file called report.html in the same folder. Open it like any file — double-click it, or run:

# Windows
start report.html
# Mac
open report.html

It'll open in your browser: a summary of errors/warnings/suggestions, grouped by category, with the exact spot in your document each one refers to.

What we need from you

Read through the report against your actual document, then tell us what you found. There's no wrong answer here — confusion and "that seems off" are exactly what we're looking for.

Did it catch real issues?

Anything it flagged that was genuinely wrong in your document.

Did it miss anything?

An issue you know is there that the report didn't mention.

Did it flag something wrongly?

A warning that didn't actually apply, or felt wrong for your document type.

Was anything confusing?

Error messages, a step above, or the report itself — tell us exactly where you got stuck.

Feedback form: fill it out here — takes a couple of minutes.
Prefer GitHub? Open an issue directly at github.com/darmsc/Academic_Document_Checker/issues, or from the PyPI page click Issue Tracker in the sidebar, then New issue. Attaching the report.html file is the single most useful thing you can send.

If something goes wrong

Quick answers before you reach out.

"pip: command not found" or "pip is not recognized"

Your Python install didn't add itself to PATH. Try python -m pip install academic-document-checker instead (or python3 -m pip install ... on Mac).

"doc-checker: command not found" after installing

Close your terminal completely and reopen it, then try doc-checker --version again. If that still fails, run python -m doc_checker.cli --version as a workaround and let us know — this is useful to hear about either way.

It says my document format isn't supported

Right now it only reads .docx, .txt, and .md files — not .doc (the older Word format) or PDF. If your file is .doc, open it in Word and use "Save As" → .docx first.

Permission denied, or it won't install

Try adding --user to the install command: pip install --user academic-document-checker.

The report flagged something I don't understand

That's exactly what we want to hear about — include the exact wording of the message when you send feedback.
